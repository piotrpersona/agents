# Workspace

Code lives in two top-level directories:

- `~/work` - work projects
- `~/developer` - personal, temporary and dev projects

## Cloning

- open source repos: `~/developer/github.com/<org>/<reponame>`
- work and private repos: `~/work/<org>/<reponame>`
- new throwaway projects: `~/developer/projects/<name>`

The `gitclone` and `mkgit` skills place these, so prefer them over a bare
`git clone` or `git init`.
